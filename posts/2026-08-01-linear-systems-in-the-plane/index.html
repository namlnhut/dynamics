Linear systems in the plane

Two numbers, the trace \(\tau\) and the determinant \(\Delta\) of \(A\), decide the phase portrait of every planar system \(\dot x = Ax\).
Author

Nam Le

Published

1 August 2026

Almost everything in this series starts from linearization, so it pays to know the linear case completely. Consider \[ \dot x = A x, \qquad x \in \R^2, \quad A \in \R^{2 \times 2}. \tag{1}\] Write \(\tau = \tr A\) and \(\Delta = \det A\). The characteristic polynomial is \(\lambda^2 - \tau\lambda + \Delta\), so the eigenvalues are \[ \lambda_{\pm} = \frac{\tau \pm \sqrt{\tau^2 - 4\Delta}}{2}. \tag{2}\]

The classification

Theorem 1 (Trace–determinant classification) Suppose \(\Delta \neq 0\), so the origin is the only equilibrium of Equation 1. Then the origin is

  1. a saddle if \(\Delta < 0\);
  2. a node if \(\Delta > 0\) and \(\tau^2 > 4\Delta\): stable if \(\tau < 0\), unstable if \(\tau > 0\);
  3. a spiral if \(\Delta > 0\), \(\tau^2 < 4\Delta\) and \(\tau \neq 0\): stable if \(\tau < 0\), unstable if \(\tau > 0\);
  4. a center if \(\Delta > 0\) and \(\tau = 0\).

On the parabola \(\tau^2 = 4\Delta\) the eigenvalues coincide and the origin is a star or degenerate node.

Proof. By Equation 2, \(\lambda_+\lambda_- = \Delta\) and \(\lambda_+ + \lambda_- = \tau\). If \(\Delta < 0\) the eigenvalues are real with opposite signs, which gives a saddle. If \(\Delta > 0\) and \(\tau^2 > 4\Delta\) they are real with the same sign as \(\tau\), which gives a node. If \(\tau^2 < 4\Delta\) they are complex conjugates with real part \(\tau/2\), so solutions rotate while growing, decaying or, when \(\tau = 0\), keeping their size.

Figure 1 draws the regions of Theorem 1, and Figure 2 shows one phase portrait from each.

tau = np.linspace(-4, 4, 400)

def draw(fig, ax, c):
    ax.plot(tau, tau**2 / 4, color=c.accent, lw=1.6)
    ax.axhline(0, color=c.fg, lw=1)
    ax.plot([0, 0], [0, 4.5], color=c.accent2, lw=1.6)
    labels = [(0, -1.4, "saddles"), (-3.2, 1.0, "stable\nnodes"), (3.2, 1.0, "unstable\nnodes"),
              (-1.2, 3.2, "stable\nspirals"), (1.2, 3.2, "unstable\nspirals"), (0.15, 4.2, "centers")]
    for x, y, s in labels:
        ax.text(x, y, s, ha="left" if s == "centers" else "center", va="center", fontsize=10)
    ax.set(xlim=(-4, 4), ylim=(-2.5, 4.5), xlabel=r"$\tau = \mathrm{tr}\,A$", ylabel=r"$\Delta = \det A$")

themed(draw)
Code 
cases = [("Saddle", [[1, 0], [0, -1]]), ("Stable node", [[-2, 0], [0, -0.5]]),
         ("Stable spiral", [[-0.3, 1], [-1, -0.3]]), ("Center", [[0, 1], [-1, 0]])]
g = np.linspace(-2, 2, 25)
X, Y = np.meshgrid(g, g)

def draw(fig, axes, c):
    for ax, (name, A) in zip(axes.flat, cases):
        A = np.array(A, dtype=float)
        U, V = A[0, 0] * X + A[0, 1] * Y, A[1, 0] * X + A[1, 1] * Y
        ax.streamplot(X, Y, U, V, color=c.accent, density=0.9, linewidth=0.7, arrowsize=0.8)
        ax.plot(0, 0, "o", color=c.fg, ms=4)
        ax.set_title(f"{name}   τ = {np.trace(A):.2g}, Δ = {np.linalg.det(A):.2g}", fontsize=10)
        ax.set(xticks=[], yticks=[], aspect="equal")

themed(draw, 2, 2, figsize=(7, 7))

Hyperbolicity

The classification also says when linearization can be trusted. An equilibrium is hyperbolic when no eigenvalue has zero real part, and the Hartman–Grobman theorem says that near a hyperbolic equilibrium a nonlinear flow looks like its linearization.

Proposition 1 The origin of Equation 1 is hyperbolic if and only if \(\Delta \neq 0\), and \(\tau \neq 0\) or \(\Delta < 0\).

Proof. An eigenvalue is zero exactly when \(\Delta = 0\). A nonzero eigenvalue is purely imaginary exactly when the eigenvalues are \(\pm i\sqrt{\Delta}\), that is, when \(\tau = 0\) and \(\Delta > 0\).

So of the regions in Figure 1, only the centers (and the line \(\Delta = 0\)) are fragile: an arbitrarily small nonlinear term can turn a linear center into a spiral in either direction. That fragility is where the Hopf bifurcation lives.

Example: the damped oscillator

Example 1 The oscillator \(\ddot x + b\dot x + x = 0\) with \(b \geq 0\) becomes Equation 1 with \[ A = \begin{pmatrix} 0 & 1 \\ -1 & -b \end{pmatrix}, \qquad \tau = -b, \quad \Delta = 1. \] As \(b\) increases from \(0\) the system moves left along the line \(\Delta = 1\) in Figure 1. It is a center at \(b = 0\), a stable spiral for \(0 < b < 2\) (underdamped), and a stable node for \(b > 2\) (overdamped). The critical damping \(b = 2\) is where the line meets the parabola.

The standard references are Strogatz (2015, ch. 5) and Hirsch et al. (2013, ch. 4).
